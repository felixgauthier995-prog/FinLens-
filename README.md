# FinLens

Next.js financial news app with Supabase, Finnhub, FMP, OpenAI and an embedded Sanity editorial Studio.

Start: `npm install`, `npm run dev`. Validate: `npm test`, `npm run lint`, `npm run build`.

Read [activation and verification guide](docs/READINESS.md) before using real services or deploying. Demo data is enabled only by `NEXT_PUBLIC_DEMO_MODE=true` and is labeled. Private credentials stay in ignored environment files / the hosting provider secret settings.
